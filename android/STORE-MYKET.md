# انتشار در مایکت (و یادداشت کافه‌بازار) — تیتانلی

## الزامات فنی که همین پروژه دارد
| قانون مایکت | وضعیت |
|---|---|
| `targetSdkVersion ≥ 34` — از **۱ آبان ۱۴۰۵** انتشار اپ/به‌روزرسانی با target پایین‌تر ممکن نیست (`myket.ir/kb` → «الزام به‌روزرسانی Target SDK Version به API Level 34») | `targetSdk 36` ✓ بالاتر از الزام |
| `minSdk` معقول (پوشش دستگاه‌های ایرانی) | `minSdk 24` (اندروید ۷) ✓ |
| فایل نصبی: **APK امضاشده** یا **AAB** | `tools/build-release.sh` هر دو را می‌سازد؛ برای مایکت همان `app-release.apk` ساده‌تر است |
| نبود وابستگی به سرویس‌های گوگل (برای کاربر ایرانی مهم است) | پروژه هیچ GMS/Firebase ندارد؛ فقط `androidx.appcompat` · `swiperefreshlayout` · `webkit` ✓ |
| آیکون ۵۱۲×۵۱۲ PNG، مربعی، بدون شفافیت آزاردهنده | `store/icon-512.png` (از `icon-512.png` سایت) ✓ |
| بدون permission غیرضروری | `INTERNET`، `ACCESS_NETWORK_STATE`، `VIBRATE`، `WRITE_EXTERNAL_STORAGE(≤28)` ✓ |
| محتوا همنوا با قوانین محتوا (حجاب/عفت، بی‌خشونت، بی‌تبعیض…) | اپ ویترین یک کارگاه خیاطی است ✓؛ عکس‌ها را خودتان روی سایت می‌گذارید، پس مسئولیت محتوا با شماست |
| عدم کپی‌بودن/تکراری‌بودن برنامه | نام بسته یکتا (`ir.titanali1.app`) + برند اختصاصی + قابلیت‌های بومی ✓ |

## ثبت‌نام توسعه‌دهنده (یک‌بار)
- پنل: <https://myket.ir> → «پنل توسعه‌دهندگان» (برای حساب‌های حقوقی: مجوز/آگهی، برای حقیقی: کد ملی +
  شماره کارت و حساب به نام خودِ شخص).
- اطلاعات مالی و شماره شبا برای تصفیه‌حساب؛ اگر برنامه رایگان است، قراردادی لازم نیست ولی
  پروفایل کامل الزامی است.
- **رزرو شناسه**: اگر فایل/APK هنوز آماده نیست، در پنل «رزرو شناسه» را بزنید و شناسهٔ رزرو را
  نگه دارید؛ هنگام آپلود همان را وارد می‌کنید.

## مراحل آپلود
1. **برنامه‌ها → افزودن برنامه**.
2. فایل: `android/app/build/outputs/apk/release/app-release.apk`
   (اگر AAB می‌فرستید، مایکت خودش APKهای تقسیم‌شده را می‌سازد؛ برای اولین انتشار APK مطمئن‌تر است.)
3. **اطلاعات پایه** (فارسی، چون مخاطب اصلی ایرانی است):
   - نام نمایشی: `تیتانلی — طراحی و دوخت`
   - بسته‌ی‌نام (package): `ir.titanali1.app` — باید دقیقاً با `titanali.appId` یکی باشد
   - دسته‌بندی: `خرید و فروش` → `پوشاک و زمان` (یا `سبک زندگی`)
   - نوع برنامه: رایگان · بدون خرید درون‌برنامه‌ای ✓ (اگر روزی پرداخت گذاشتید، باید
     Myket IAP جای Google Play Billing بنشیند)
   - توضیح کوتاه (تا ۸۶ نویسه): «طرح‌های دوخت، ثبت سفارش در گفتگو، تماس با کارگاه — آفلاین هم کار می‌کند»
   - توضیح کامل: ۳ تا ۶ خط از معرفی سایت + این نکته‌ها: «ارسال عکس از دوربین برای سفارش، دریافت
     پاسخ کارگاه، بدون نیاز به فیلترشکن و سرویس گوگل، کارکرد آفلاین».
4. **تصاویر**: آیکون ۵۱۲ از `store/icon-512.png`؛ حداقل ۳ تا ۵ اسکرین‌شات ۹:۱۹.۵ یا ۱۶:۹ از
   داخل اپ (خانه، گالری، گفتگو با فرم نام/شماره، صفحهٔ آفلاین، پاسخ کارگاه). سایز پیشنهادیِ
   مایکت در همان فرم نوشته شده — همان را نگه دارید (معمولاً عرض ۱۰۸۰).
5. **آپدیت‌رسانی / تغییرات نسخه**: همان یادداشت ریلیز.
6. **اطلاعات تماس پشتیبانی**: ایمیل + شمارهٔ کارگاه (مایکت این را برای «درخواست کاربر» الزامی می‌کند).
7. ارسال برای بازبینی. معمولاً چند ساعت تا ۲ روز کاری. وضعیت در پنل و ایمیل می‌آید.

## نکات مهم مخصوص این اپ
- **CORS**: مثل گوگل‌پلی، مایکت هم فرقی نمی‌کند — تا `appOrigins` در `titanali-config.php` ست نشود،
  پیام گفتگو از اپ به هاست نمی‌رسد (بند ۵ `BUILD.md`).
- **آپدیت‌ها**: مایکت نسخهٔ امضاشده با همان کلید را قبول می‌کند؛ اگر `titanali-release.jks` را گم
  کنید، عملاً باید برنامه را از نو با نام بستهٔ دیگر منتشر کنید.
- **تبلیغات**: اگر روزی AdMob/بیلد تبلیغاتی اضافه کردید، هم در مایکت و هم در فرم Data safety
  پلی باید اعلام شود.
- **اعلان پیامک/پیام**: ما اعلان push نداریم (FCM داخل ایران دردسر دارد). اگر خواستید،
  «Myket Push» را ببینید؛ فعلاً اپ با باز شدن، صندوق را از `api.php` می‌گیرد.
- **کافه‌بازار**: همان `app-release.apk`/AAB و همان آیکون ۵۱۲ قابل استفاده است (پیشخان:
  `developers.cafebazaar.ir`)؛ تنها فرق‌ها: `targetSdk ≥ 33/34` را چک کنید و در فرم «پیش‌نیازها»
  گزینهٔ «بدون نیاز به گوگل پلی سرویس» را علامت بزنید.

## چک‌لیست پیش از ارسال
```bash
cd android
python3 tools/prepare-web.py --check            # پوسته با index.html هم‌زمان باشد
python3 tools/prepare-icons.py                  # آیکون‌های تازه
bash tools/build-release.sh                     # APK + AAB امضاشده
aapt2 dump badging app/build/outputs/apk/release/app-release.apk | head -4
#   package: name='ir.titanali1.app'
#   versionCode='10008' versionName='1.0.8'
#   minSdkVersion:'24'  targetSdkVersion:'36'
apksigner verify --print-certs app/build/outputs/apk/release/app-release.apk
```
