# dmj74 — پروفایل شخصی به‌سبک iOS 26 (Liquid Glass)

تک‌فایل، بدون فریم‌ورک، بدون بیلد، بدون وابستگی شبکه: همه‌ی CSS و JS داخل `index.html` است.
فونت‌ها سیستم‌اند، همه‌ی تصویرهای نمونه به‌صورت SVG درون‌خطی (`data:`) تولید می‌شوند،
و داده‌ها در `localStorage` می‌نشینند — پس آفلاین هم کار می‌کند.

## اجرا

```bash
python3 -m http.server 8000      # یا index.html را مستقیم در مرورگر باز کنید
open http://localhost:8000
```

## ویوها

| ویو | مسیر | توضیح |
|---|---|---|
| خانه | `#home` | هیرو پروفایل، آمار، درباره، مهارت‌ها (نوار درصد)، علاقه‌مندی‌ها، پیش‌نمایش نمونه‌کار و تماس |
| گالری | `#gallery` | شبکه‌ی ۳ستونه با فیلتر دسته‌ها، لایت‌باکس با سوا이프/کلید جهت‌دار |
| گفتگو | `#chat` | حباب‌های iOS، ذخیره‌ی محلی پیام‌ها، ارسال برون‌سپاری‌شده به تلگرام/واتساپ/ایمیل، بَج شمارش |
| موسیقی | `#music` | پخش‌کننده با `seek`؛ اگر `src` تنظیم شده باشد فایل واقعی پخش می‌شود، وگرنه پیش‌نمایشِ ملودی با WebAudio |
| پروژه‌ها | `#projects` | فیلتر بر اساس وضعیت، برچسب‌ها، دکمه‌های نمایش/کد |
| اجتماعی | `#social` | کاشی‌های ارتباطی + لیست کامل تماس‌ها با دکمه‌ی کپی |

ناوبری: داک پایین (۵ آیکون)، دراور کشویی، و نوار وضعیت آیفون با ساعت زنده.
`fa` راست‌به‌چپ و `en` چپ‌به‌راست — با یک دکمه در دراور عوض می‌شود و `dir`/`lang`/متاتگ‌های OG و Twitter هم به‌روز می‌شوند.

## پنل مدیریت

دراور → «ویرایش محتوا». پروفایل با فیلد، و بقیه‌ی بخش‌ها با ویرایشگر JSON (اعتبارسنجی + توست خطا).
دکمه‌ها: ذخیره، خروجی JSON، ورودی JSON، بازنشانی. ذخیره فقط در مرورگر خودتان است و جایی ارسال نمی‌شود.

برای ویرایش مستقیم، شیء `DEFAULTS` را در اسکریپت همان فایل عوض کنید.

## انتشار

- **GitHub Pages:** پایپ‌لاین [`.github/workflows/pages.yml`](.github/workflows/pages.yml) با هر پوش روی `main`، ریشه‌ی مخزن را منتشر می‌کند (کافی است در Settings → Pages منبع را روی *GitHub Actions* بگذارید).
- **دامنه‌ی شخصی:** `canonical` و لینک‌های OG روی `https://dmj74.ir/` تنظیم شده‌اند؛ برای پیش‌نمایش لینک در شبکه‌های اجتماعی دو فایل `og.png` (1200×630) و `apple-touch-icon.png` را کنار `index.html` بگذارید.
