# dmj74.ir — قالب «Aurora Glass»

طراحی کامل قالب (Template) سایت شخصی **dmj74.ir** — یک پروفایل شخصی فارسی، راست‌چین (RTL)، تک‌صفحه‌ای با ناوبری داک پایین، به‌همراه **پنل مدیریت** برای ویرایش همه‌ی محتوا بدون دست‌زدن به کد.

> اجرا بدون هیچ بیلد و وابستگی: فقط HTML + CSS + JS خالص. روی GitHub Pages، Netlify یا هر هاست استاتیک دیگر مستقیم بالا می‌آید.

---

## ✨ نگاه کلی به طراحی

| ویژگی | توضیح |
|---|---|
| زبان و جهت | فارسی، `dir="rtl"`، اعداد فارسی در سراسر رابط |
| تایپوگرافی | **Vazirmatn** (متن) + **Vazirmatn RD** (تیترها) + **Vazirmatn FD** (اعداد) — همگی لوکال و Vendored |
| سبک بصری | شیشه‌ای (Glassmorphism) روی پس‌زمینه‌ی «شفق» (Aurora) با Orb های متحرک و نویز ظریف |
| حالت‌ها | تاریک (پیش‌فرض) و روشن |
| تم‌های رنگی | ۴ لهجه‌ی رنگی: شفق (بنفش–فیروزه‌ای)، غروب (صورتی–کهربایی)، زمرد، اقیانوس |
| ناوبری | داک شیشه‌ای شناور پایین + هدر چسبان (Sticky) |
| دسترس‌پذیری | `aria-label`، استایل فوکوس مشخص، پشتیبان `prefers-reduced-motion` |

### توکن‌های طراحی (`assets/css/base.css`)
- **رنگ:** متغیرهای `--bg / --surface / --stroke / --text / --muted` برای هر حالت + `--a1 / --a2` برای گرادیان لهجه‌ی رنگی.
- **شعاع:** `--r-xs … --r-xl` و `--r-full`.
- **سایه:** `--sh-1 … --sh-3` و `--sh-glow` (هاله‌ی رنگی هنگام hover).
- **حرکت:** `--t-fast / --t / --t-slow` با منحنی `cubic-bezier(.22,.8,.3,1)`.
- **فاصله:** مقیاس `--s-1 … --s-9`.

## 🧩 بخش‌های سایت عمومی

روتینگ با هش (`#/skills` و …) — بدون رفرش صفحه:

1. **عمومی (خانه)** — کارت قهرمان (آواتار، نام، نقش، شعار، درباره‌من)، نوار آمار، کاشی‌های «بخش‌های سایت»
2. **مهارت‌ها** — گروه‌های مهارت با نوار سطح انیمیشنی
3. **نمونه‌کارها** — کارت با کاور، سال، وضعیت، برچسب و لینک
4. **گالری تصاویر** — چیدمان ستونی (Masonry) + لایت‌باکس با کلیدهای جهت‌نما
5. **موسیقی** — لیست پخش + پخش‌کننده‌ی شناور بالای داک (اگر فایل صدا نباشد، پخشِ شبیه‌سازی‌شده)
6. **پروژه‌ها** — کارت پروژه با برچسب/لینک/فایل
7. **علاقه‌مندی‌ها** — چیپ‌های بزرگ آیکون‌دار
8. **شبکه‌های اجتماعی** — کاشی‌های رنگی؛ موارد بدون آیدی کم‌رنگ می‌مانند
9. **پیام مستقیم** — فرم پیام (اگر «آدرس سرویس فرم» در تنظیمات خالی باشد، فرم غیرفعال می‌ماند)

## 🛠 پنل مدیریت (`admin.html`)

ورود پیش‌فرض: `admin / admin123`

تب‌ها: **عمومی · مهارت‌ها · نمونه‌کارها · پروژه‌ها · گالری · موسیقی · شبکه‌ها/تماس‌ها · پیام‌ها · تنظیمات · فضای ابری (GitHub) · پشتیبان‌گیری**

- ویرایش‌ها **زنده** روی داده اعمال می‌شوند و با دکمه‌ی «ذخیره» در `localStorage` نگه داشته می‌شوند.
- آپلود تصویر/کاور مستقیم از فایل (به‌صورت data-URL) یا با لینک.
- **صندوق پیام‌ها** با فیلتر همه / خوانده‌نشده / پاسخ‌داده‌شده.
- **فضای ابری:** با توکن Fine-grained گیت‌هاب، هر ذخیره مستقیم به‌صورت `PUT` روی `data/site.json` مخزن نوشته می‌شود تا تغییرات برای همه‌ی بازدیدکننده‌ها زنده شود.
- **پشتیبان‌گیری:** خروجی/بازگردانی JSON و بازگشت به داده‌ی پیش‌فرض.

## 🚀 اجرا و استقرار

```bash
# لوکال
python3 -m http.server 8080        # یا هر سرور استاتیک دیگر
# سپس: http://localhost:8080

# استقرار
کل پوشه را روی GitHub Pages / Netlify / Cloudflare Pages آپلود کن.
```

### سفارشی‌سازی سریع
- محتوا: `data/site.json` (یا از پنل مدیریت)
- رنگ لهجه: `assets/css/base.css` → بلوک `[data-accent="..."]`
- تصویر زمینه پیش‌فرض: `appearance.background` در داده
- فونت‌ها تحت پروانه‌ی **SIL OFL** هستند (متن `assets/fonts/OFL.txt`).
