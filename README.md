# titanali — طراحی و دوخت (به‌سبک iOS 26 Liquid Glass)

تک‌فایل، بدون فریم‌ورک، بدون بیلد، بدون وابستگی شبکه: همه‌ی CSS و JS داخل `index.html` است.
فونت‌ها سیستم‌اند، تصویرهای جانشین به‌صورت SVG درون‌خطی تولید می‌شوند، و داده‌ها در `localStorage` می‌مانند — آفلاین هم کار می‌کند.

> نسخه‌ی ۲: نام `titanali`، شعار «طراحی و دوخت تیتانلی»، گالری مبتنی بر دسته‌های
> «طرح های جدید · پلیواری · تمام کش · دانوکی · بنوک ها» و پنل مدیریت تصویری.
> بخش‌های **مهارت‌ها، موسیقی و پروژه‌ها** حذف شدند.

## اجرا

```bash
python3 -m http.server 8000      # یا index.html را مستقیم در مرورگر باز کنید
```

## ویوها (۴ تا)

| ویو | مسیر | توضیح |
|---|---|---|
| خانه | `#home` | هیرو کارگاه، آمار، درباره‌ی کارگاه، لیست دسته‌ها با شمارش طرح، برچسب‌های کاری، ۳ طرح منتخب، راه‌های سفارش |
| طرح‌ها | `#gallery` | تب دسته‌ها، بنر توضیح هر دسته، شبکه‌ی ۳/۲ ستونه (دکمه‌ی ▦)، برچسب «جدید»، لایت‌باکس با توضیح + سوا이프/کلید + دکمه‌ی سفارش |
| گفتگو | `#chat` | حباب‌های iOS، ذخیره‌ی محلی، بَج داک، ارسال همان متن به تلگرام/واتساپ/ایمیل |
| ارتباط | `#social` | کاشی‌های سفارش و مشاوره + لیست تماس‌ها با دکمه‌ی کپی |

دوزبانه `fa`(RTL)/`en`(LTR) — با تعویض زبان، `dir`، عنوان و متاتگ‌های OG/Twitter هم به‌روز می‌شوند.

## پنل مدیریت — درج عکس و توضیحات

دراور → «ویرایش محتوا». هفت تب: **طرح‌ها**، **دسته‌ها**، کارگاه، آمار، برچسب‌ها، تماس‌ها، تنظیمات.

- تب «طرح‌ها» — برای هر طرح یک کارت ویرایش با:
  **انتخاب عکس از گالری گوشی** (یا آدرس تصویر)، عنوان، دسته (کشویی)، توضیحات، برچسب «جدید»، حذف، و «＋ افزودن طرح تازه».
  تصویر انتخابی در همان لحظه روی تامنیل پیش‌نمایش می‌آید و **قبل از ذخیره به حداکثر ۱۱۰۰ پیکسل کوچک و JPEG با کیفیت ۸۵٪ فشرده می‌شود** تا `localStorage` (سقف ~۵ مگابایت) پر نشود؛ ابعاد و حجم نهایی در اعلان نمایش داده می‌شود.
- تب «دسته‌ها» — نام + توضیح (بنر بالای گالری) + image شاخه برای هر دسته، افزودن/حذف دسته. حذف دسته، طرح‌هایش را بی‌دسته می‌کند (پاک نمی‌کند).
- تب‌های آمار/برچسب‌ها/تماس‌ها با ویرایشگر JSON + اعتبارسنجی (JSON خراب ذخیره نمی‌شود).
- «خروجی JSON» فایل `titanali-data.json` می‌دهد؛ با «ورودی JSON» روی هر دستگاهی بارگذاری کنید.

## ساختار داده

```js
{ profile:{name,initials,role,tagline,loves,location,availability,avatar,bio},
  stats:[{k,v}],
  cats:[{t,desc,img?}],
  gallery:[{t,cat,img?,desc,n?}],          // n=1 → برچسب «جدید»
  hobbies:[{ic,t}], contacts:[{label,kind,id}],
  quick:[…], messages:[{me,text,ts}], settings:{lang,bg,grid,theme} }
```

`kind` تماس‌ها: `telegram · whatsapp · email · instagram · github · website · phone · x · link`.
